# T148 — 멈춤(점형)·선형 점자블록 오발화: 오프라인 검증과 적용

## 금지·전제
- 검증을 마친 뒤 앱 코드를 바꾸기 전에 오케스트레이터에게 보고했다(지시 4번: 기준 충돌). 결정(2026-10-28): (1) 점형은 음성을 끈다. 사용자가 승인한 추천안 F의 "그래도 줄지 않으면 끈다"에 따른 것이다. (2) 선형은 앞 칸 15%로 올린다(2회 그대로). 바뀐 앱 코드는 `crosswalk_app/lib/services/surface_guide.dart` 한 파일이다.
- 재생 스크립트: `train/t148_tactile_yellow.py`. 실행(기록·프레임이 있는 메인 체크아웃 루트에서): `PYTHONIOENCODING=utf-8 python <워크트리>/train/t148_tactile_yellow.py --sheet <워크트리>/train/t148/sheet.jpg` → exit 0, `train/t148/events.csv`, `train/t148/summary.json`, `train/t148/sheet.jpg`(이벤트별 원본 + 모델 마스크, 초록 칸 = 앞 칸).
- 근사: 앱 노면 판정은 10프레임마다 하고, 프레임은 1초에 1장 저장한다. 그래서 색 측정에는 이벤트에 가장 가까운 저장 프레임을 썼다(시각 차이 |dt| ≤ 0.6초). 앱이 본 프레임과 같지 않다. 측정 불가(앞 칸 점형/선형 < 20픽셀)는 D8·S29(점형)와 S5(선형)다.
- 모델: `crosswalk_app/assets/model/crosswalk_surface.onnx`(현재 master 자산). 빌드 18e954a와 같다고 추정한다. T145와 같은 근거다.
