## 4. 진동 방향

이미 틀었음의 진동 방향 = 끝 규칙이 보내는 **중앙 쪽**(왼쪽 끝 → left "오른쪽으로").

| 근거 | 내용 |
|---|---|
| T98 | 끝이면 각도와 무관하게 중앙 쪽으로 |
| T100 | 사용자가 중앙 쪽으로 틀고 있음 → "그대로 가세요" = 그 방향을 계속 |
| T137 | 줄무늬 방향(반대쪽) 이탈은 25° 초과일 때만 — 25° 안에서 반대 방향 진동은 "그대로"와 모순 |
| T136 | 좌우 진동 모양이 같아 지금은 체감 차이 없음. 좌우 모터 2개 기기에서 뜻이 생김 |

같은 방향이라 끝 유도 → 이미 틀었음 전환 때 진동이 끊기지 않고 박자만 느려진다. 끝을 벗어나 일반 직진이 되면 그때 회복 진동·딩이 나간다.
