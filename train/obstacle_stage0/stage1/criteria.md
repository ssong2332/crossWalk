## 입력 (T107 학습과 같은 360x480 세로)
| 영상 | 처리 |
|---|---|
| 화면 녹화 1080x2340 | 높이 480으로 줄임(폭 약 222) → 360 캔버스 가운데에 놓고 양옆은 회색(0.5). 근거: 앱은 미리보기를 cover로 채움 → 화면 = 카메라 높이 전체 + 가로 가운데 약 61.5%(`camera_screen.dart` `_buildFullBleedPreview`, ResolutionPreset.medium 4:3 가정). 화면의 UI(화살표·점선 원·아래 정보 패널)는 지울 수 없어 그대로 들어감 |
| h0 1920x1080 | 학습과 같게 853x480으로 줄이고 가운데 360x480 자름 |

## 경고 조건
| # | 조건 | 판정 |
|---|---|---|
| 1 | 프레임 간격 | 0.25초(초당 4회, 앱 주기 추정값) — `CAP_PROP_POS_MSEC` |
| 2 | 볼라드(라벨 1), 점수 ≥ 0.30 (T107 발 앞 경보에서 쓴 낮은 기준). 0.50도 같이 보고 | 검출 |
| 3 | 상자 아래 가운데 x가 '가운데 칸' 안 — 0단계 눈 판정과 같은 칸: 화면 녹화 = 화면 가운데 1/3(캔버스 x 142.8~216.6), h0 = 원본 프레임 가운데 1/3(자른 입력 x 37.8~322.2) | 칸 안 검출 |
| 4 | 칸 안 검출이 연속 2프레임 | 경고 성립 |
| 5 | 경고 성립 사이 간격 ≥ 1초면 별개 경고 | 경고 묶음 |

## 기준 ① 재현 (가운데 진입 20건)
| 조건 | 판정 |
|---|---|
| 창 = [처음보임 − 1초, 볼라드선도달 − 2.4초] 안에서 경고 성립 | 성공(후보) |
| 성공 후보 프레임을 눈으로 보고 상자가 실제 그 볼라드 | 성공 확정 / 아니면 실패 |
| 창이 비어 있음(볼라드선 − 2.4초 < 처음보임 − 1초) | 실패(시간상 불가) |
| 합격 | 성공 ≥ 16/20 |
| 참고 | 0단계 눈 판정의 가운데 진입 거리 < 3.3m인 5건은 이 기준에서 불리함 — 기준 정의상 그대로 셈, 따로도 보고 |

## 기준 ② 오경보
| 대상 | 창 |
|---|---|
| 볼라드 없는 건너기 11건 | 건너기 전체 |
| 가운데 진입 20건 | 건너기 시작 ~ 처음보임 − 1초 (가운데 칸이 빈 구간) |
| 옆 칸 5건 | 건너기 전체 (가운데에 볼라드 없음) |
- 창 안 경고 묶음 1개 = 오경보 1회. 단 눈으로 봐서 상자가 실제 볼라드(멀리 보인 같은 볼라드 포함)면 오경보에서 빼고 따로 표시.
- 합격: 오경보 수 / 건너기 수 × 20 ≤ 1.
- 애매 2건(131228, h0 165824)·연석 뒤 1건(210334 #2)은 ①②에서 빼고 참고로만.
