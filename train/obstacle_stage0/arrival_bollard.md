## 금지·전제
- 추론·학습 없음. 프레임 추출·리사이즈·선/눈금 긋기, 기록(jsonl) 읽기만 함.
- **거리는 전부 추정**: (볼라드 선에 닿은 시각 − 해당 시각) × 1.3 m/s. 사용자가 비틀거나 느려진 구간도 그대로 들어가 길게 나올 수 있음. 확인 방법: 같은 장면 줄무늬 수 세기 또는 실측.

- 사용자 결정 반영: 건너는 중 물체 경고 = 미착수(A), 경고 방식 = 진동만.

## 1. 진동만일 때 언제 울려야 하나 (추정 계산)

| 요소 | 값 | 근거 |
|---|---|---|
| 보행 속도 | 1.4 m/s | 오케스트레이터 지시 |
| 판정 지연(검출 2회 확인 포함) | 약 1초 = 1.4m | 같음, 검토 보고서 |
| 진동 알아채고 멈추기 | 약 1초 = 1.4m (가정, 미측정) | 확인: 실기기에서 진동→정지 시간 측정 |
| 여유 | 0.5m | 가정 |
| **검출이 시작돼야 하는 거리** | **약 3.3m 이상** | 1.4+1.4+0.5 |
| 이 기준을 맞출 수 있는 건 | 가운데 진입이 ≥3.3m인 **15/20** | csv. 나머지 5건은 사용자가 휘어 걸어 볼라드가 늦게 가운데로 들어옴 → 기하학적으로 늦음 |

겹침:
- 가운데 진입 순간 9/14가 left/right 상태 → **이탈 진동과 시간이 겹침**. 볼라드 진동은 촉감이 확실히 달라야 함(예: 길게 1번, 이탈은 짧은 반복 `[0,125,125,125]` — `logs/log_20261019_164736.jsonl` vib 기록).
- '건넜습니다'는 가운데 진입 +1.0~8.0s 뒤 음성. 기록상 crossed 진동은 없음(vib kind는 left/right/recover/road/line_on만) → 진동 채널 충돌은 이탈 진동뿐.
- 볼라드를 피하면 방향이 틀어져 이탈 진동이 다시 울릴 수 있음(검토 보고서 문제 2와 같은 구조).

## 2. T107 검출기가 이 시점에서 쓸 만한가 (의견)
- 크기: 가운데 진입 거리(약 3~5m)에서 볼라드는 입력 기준 약 29~58px로 **학습 중앙값(26px)과 같거나 큼** → 크기 면에서는 불리하지 않음(추정). 6m 넘는 먼 볼라드(14px)는 작음 — 다만 그 거리는 경고에 필요 없음.
- 불리한 점: 학습 데이터는 인도 위 낮은 수평 시점, 이 영상은 위에서 약 30° 내려다봄 → 볼라드 윗면·줄무늬 모양이 다름. 야간 영상 많음(9/29, h0 night). 낮은 돌 공 볼라드(10/12 182734)는 학습에 있는지 미확인.
- T107 자체 성능이 약함: 가까운 볼라드 AP50 0.482(75상자). → **쓸 만한지 판단할 근거 부족, PC 시험 필요**.
- 크기 계산 가정(화면 높이 = 카메라 프레임 높이)은 미확인. 확인 방법: `camera` 기록의 preview 크기와 앱 입력 크기 비교, 또는 디버그 박스로 실측.
