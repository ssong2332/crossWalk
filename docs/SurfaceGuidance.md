# 노면 안내 판정표 (B: 점자블록 따라가기 / 인도→차도 이탈)

**상태: 사용자 확정 (2026-09-30, Q1~Q4 제안안 채택).** 기준값은 추정이다(§6) — 구현 전 이벤트 단위 평가, 구현 후 실기기 조정. 태스크: `docs/Tasks.md` T104.
입력 모델: `model/crosswalk_surface_t104.onnx` (LR-ASPP MobileNetV3-Small, 224, 클래스 6).

## 금지 (다른 모든 규칙보다 우선)
- 이 표에 없는 상황에서 말하지 않는다. 표에 없는 상황이 나오면 행을 추가할지 사용자에게 묻는다.
- **횡단보도 안내가 도는 동안(분류기 위·hold) 노면 안내는 말하지 않는다.** 횡단보도 위에서는 차도 픽셀이 정상이다.
- 노면 안내가 이탈 경고(P0)를 끊거나 늦추게 하지 않는다. `docs/AudioPolicy.md`의 끊기 판정표를 그대로 따른다.
- 분할 결과 한 번만으로 말하지 않는다. 연속 확인(§2)을 통과한 변화만 안내한다.

## 1. 입력 — 분할 결과에서 무엇을 읽는가

분할 출력(224×224)의 **아래 절반**을 가로 3칸으로 나눈다. 가운데 칸은 학습 평가의 "발 앞 영역"과 같다.

| 영역 | 범위 (가로 × 세로) | 뜻 |
|---|---|---|
| **앞 (F)** | 가운데 1/3 × 아래 1/2 | 발 앞 |
| **왼쪽 (L)** | 왼쪽 1/3 × 아래 1/2 | 왼발 옆 |
| **오른쪽 (R)** | 오른쪽 1/3 × 아래 1/2 | 오른발 옆 |

각 영역에서 클래스별 **면적 비율**을 구한다. "있음" = 그 영역의 5% 이상 (학습 평가와 같은 기준).

| 값 | 정의 | 평가 근거 (test 4,718장, 앞 영역) |
|---|---|---|
| 앞 선형 있음 | F의 선형 ≥ 5% | 재현 97.7% · 정밀도 76.2% |
| 앞 점형 있음 | F의 점형 ≥ 5% | 재현 93.6% · 정밀도 84.2% |
| 앞 차도 많음 | F의 차도 ≥ 50% | 5% 기준 재현 90.4% · 정밀도 90.3% (**50% 기준은 미측정**) |
| 앞 인도 많음 | F의 인도 ≥ 50% | 5% 기준 재현 95.7% · 정밀도 91.8% (**50% 기준은 미측정**) |
| 옆 선형 있음 | L 또는 R의 선형 ≥ 5% | **미측정** |

## 2. 언제 판정하는가

| 규칙 | 값 | 근거 |
|---|---|---|
| 분할 실행 | 처리 프레임 10개 중 1번 (분류 0·5, 각도 3, 위치 7과 겹치지 않는 9번째) | 실기기 측정 빌드와 같은 배치 (T104 (5)) |
| 연속 확인 | **같은 판정이 분할 결과 2번 연속**일 때만 상태를 바꾼다 | 추정 — 한 번의 오판으로 말하지 않기 위함. 지연은 약 0.7~2초 (추정) |
| 모드 | 분류기 상태가 **none 또는 crossed**일 때만 노면 안내 활성 | 금지 규칙 2번. approach는 §3 표 참고 |

## 3. 판정표

| # | 분류기 상태 | 조건 (연속 확인 후) | 안내 | 등급 | 반복 |
|---|---|---|---|---|---|
| 1 | none / crossed | **직전 3초 안에 앞 인도 많음** → 지금 **앞 차도 많음** (인도→차도 전이) | "차도입니다" | **P0** | 전이 1회 + 앞 차도 많음이 이어지면 3초마다 (이탈 경고와 같은 박자) |
| 2 | none / crossed | 처음부터 앞 차도 많음 (전이 없음 — 골목·인도 없는 길) | "차도입니다" **1회** (Q1 확정) | P0 (1번과 같은 말·같은 뜻) | 1회. 앞 차도 많음이 3초 이상 없었다가 다시 나타나야 다시 말함 |
| 3 | none / crossed | 앞 점형 없음 → **있음** | "멈춤 블록입니다" | P1 | 1회. 앞 점형이 3초 이상 없었다가 다시 나타나야 다시 말함 |
| 4 | approach | 앞 점형 있음 | 침묵 — "앞에 횡단보도가 있습니다"(기존)와 겹침 | — | — |
| 5 | none / crossed | 앞 선형 없음 → **있음** (블록 위에 올라섬) | 음성 없음, 짧은 확인 진동 1회 | — | 1회 |
| 6 | none / crossed | 직전에 앞 선형 있음 → 앞 없음 + **오른쪽 선형 있음** | "점자블록 오른쪽" (Q2 확정) | P2 | 1회, 앞 선형으로 돌아오면 재무장 |
| 7 | none / crossed | 직전에 앞 선형 있음 → 앞 없음 + **왼쪽 선형 있음** | "점자블록 왼쪽" (Q2 확정) | P2 | 6번과 같음 |
| 8 | none / crossed | 직전에 앞 선형 있음 → 앞·왼쪽·오른쪽 **모두 선형 없음**이 2초 이상 | "점자블록을 벗어났습니다" | P2 | 1회 |
| 9 | 위(front/left/right) / hold | 무엇이든 | 침묵 (횡단보도 안내 우선) | — | — |
| 10 | 무판정·오류 | 무엇이든 | 침묵 | — | — |

**우선순위가 겹칠 때**: 1번(P0)은 `AudioPolicy` 끊기 판정표대로 다른 안내를 즉시 끊는다. 3번(P1)·6~8번(P2)은 무음 예산(1.5초 간격, 60초에 20초)을 따른다 — 예산에 걸리면 버린다(큐에 쌓지 않음).

## 4. 진동 (Q3 확정)

기존 패턴(`docs/AudioPolicy.md` §5): 왼쪽 이탈 ‧‧ / 오른쪽 이탈 — / 복귀 아주 짧게 1번.

| 안내 | 제안 패턴 | 이유 |
|---|---|---|
| 1·2번 차도 | 짧게 **3번** (‧‧‧) | 기존 패턴과 겹치지 않는 새 패턴 — 가장 위험하므로 음성 없이도 구분돼야 함 |
| 5번 블록 위 | 아주 짧게 1번 (복귀 패턴 재사용) | "맞게 가고 있음" 의미가 같음 |
| 3·6·7·8번 | 진동 없음 (제안) | 기존 좌/우 패턴은 "이탈 방향"을 뜻해, 블록 위치 안내에 쓰면 뜻이 반대로 읽힐 수 있음 |

## 6. 이 문서의 값은 추정이다

50% 기준, 연속 2회, 3초 재무장, 2초 벗어남 — 전부 설계 제안이다. 앞 영역 5% 기준만 test로 쟀다.
구현 전에 test 데이터로 **이벤트 단위**(전이·등장) 재현율·정밀도를 재고, 실기기 보행으로 조정한다.
