# 오디오 우선순위 정책

사용자 확정: 2026-08-24. 구현: `crosswalk_app/lib/services/audio_policy.dart`.

## 금지 (다른 모든 규칙보다 우선)
- **P0(안전 경고)를 지연·억제하지 말 것.** 무음 예산·최소 간격은 P0에 적용되지 않는다.
- 낮은 등급을 **큐에 쌓지 말 것.** 늦게 도착한 안내는 정보가 아니라 오정보다.
- 이 표에 없는 상황이 나오면 임의 판단하지 말고 표에 행을 추가할지 물을 것.

## 왜 필요한가

시각장애인은 **청각으로 교통 상황을 파악한다.** 앱이 말하는 동안 그 채널이 점유된다.
확장 후보를 모두 더하면 이탈 경고 + 경로 안내 + 신호등 + 물체 경고가 **같은 채널을 두고 경쟁**한다.

정책 도입 전 상태(2026-08-24 실측, `feedback_service.dart`):

| 항목 | 이전 동작 |
|---|---|
| 끊기 규칙 | `_speak()`가 항상 `await _tts.stop()` 먼저 → **나중에 온 말이 무조건 이김** |
| 무음 보장 | 없음 |
| 좌/우 진동 | **완전히 같은 패턴** — 방향 정보가 음성에만 존재 |

마지막 항목이 특히 문제였다. 도로 소음에 음성이 묻히면 **방향 정보가 통째로 사라진다.**

## 1. 우선순위 4등급

| 등급 | 성격 | 현재 사용처 | 확장 시 |
|---|---|---|---|
| **P0** | 지금 위험. 늦으면 다침 | 이탈 경고(left/right) | 접근하는 자전거·차 |
| **P1** | 곧 행동해야 함 | — | 신호 변화, 경로 회전 지점 |
| **P2** | 알면 좋음 | — | `approach` 방향 안내, 도착 |
| **P3** | 앱 상태 | 오류 안내, 온보딩 낭독 | 설정 확인음 |

## 2. 끊기 판정표 (재생 중 ↓ / 새 요청 →)

| | P0 | P1 | P2 | P3 |
|---|---|---|---|---|
| **P0 재생 중** | 끊고 교체 | **대기** | 버림 | 버림 |
| **P1 재생 중** | 즉시 끊음 | 끊고 교체 | 버림 | 버림 |
| **P2 재생 중** | 즉시 끊음 | 즉시 끊음 | 끊고 교체 | 버림 |
| **P3 재생 중** | 즉시 끊음 | 즉시 끊음 | 즉시 끊음 | 끊고 교체 |
| **재생 없음** | 즉시 발화 | 예산 검사 후 발화 | 예산 검사 후 발화 | 예산 검사 후 발화 |

"P0 재생 중 + P0 요청"이 끊고 교체인 이유: 같은 방향의 반복은 이 층에 도달하기 전에
`decideMessage`의 쿨다운에서 걸러진다. 여기까지 온 P0는 **방향이 바뀐 경우**뿐이다.

**대기는 P1이 P0를 기다리는 한 칸뿐이고, 대기 슬롯은 1개다.** 더 높은 등급이 오면 덮어쓴다.

## 3. 유효기간 (TTL) — 늦으면 버림

| 등급 | TTL |
|---|---|
| P0 | 1초 |
| P1 | 3초 |
| P2 | 5초 |
| P3 | 0초 (즉시 아니면 버림) |

대기 슬롯의 항목도 TTL이 지나면 발화하지 않고 버린다.

## 4. 무음 보장

| 규칙 | 값 | P0 적용 |
|---|---|---|
| 발화 사이 최소 무음 | **1.5초** | **면제** |
| 60초 이동창 발화 상한 | **20초** | **면제** |

P0만 면제하는 이유: 그것만이 "지금 안 들으면 다치는" 정보다.
P0 발화 시간은 예산에 **누적되지 않는다** — 안전 경고가 이후의 안전 경고를 막으면 안 된다.

## 5. 음성을 진동으로 옮기기

음성은 희소 자원이고 진동은 상대적으로 남는다.

| 상황 | 음성 | 진동 |
|---|---|---|
| 첫 이탈 경고 | 발화 | 방향 패턴 |
| **같은 방향 계속** | **침묵** | 방향 패턴 반복 (간격 점증) |
| 반대 방향으로 바뀜 | 발화 | 새 방향 패턴 |
| 정상 복귀(front) | 침묵 | 짧은 확인 진동 1회 |
| none / approach | 침묵 | 없음 |

### 진동 패턴

| 방향 | 패턴 | 의미 |
|---|---|---|
| 왼쪽 | 짧게 **2번** (‧‧) | 왼쪽으로 벗어남 |
| 오른쪽 | 길게 **1번** (—) | 오른쪽으로 벗어남 |
| 정상 복귀 | 아주 짧게 1번 | 돌아옴 |

짧은 진동 = 설정된 진동 길이의 1/4 (하한 80ms), 긴 진동 = 설정값 그대로.
사용자가 설정에서 진동 길이를 바꾸면 두 패턴이 함께 비례한다.

### 반복 간격 점증

같은 방향이 계속되면 진동 간격을 1초 → 2초 → 4초 → 8초로 늘리고 8초에서 고정한다.
방향이 바뀌거나 정상으로 복귀하면 1초로 초기화한다.

## 6. 사용자가 끌 수 있는 것

| 등급 | 끄기 |
|---|---|
| P0 | **불가** (또는 끌 때 명시적 경고 후) |
| P1~P3 | 개별 가능 |

## 7. 미해결 (구현하며 남긴 우려)

**지속되는 이탈에서 음성이 영구히 침묵한다.** 5절 표대로면 같은 방향이 계속될 때
음성은 첫 1회뿐이고 이후에는 진동만 나간다. 사용자가 첫 음성을 놓쳤다면
(도로 소음, 통화 중, 이어폰 미착용) 방향 정보를 다시 들을 기회가 없다.

이 문서는 확정된 표를 그대로 구현한 것이며, 위 우려는 **실기기 보행 테스트로 확인한 뒤**
"N초 이상 지속되면 음성 1회 재발화" 같은 안전망을 추가할지 결정한다.
추정으로 값을 정해 넣지 않는다.

## 8. 이 문서의 값들은 추정이다

1.5초, 20초/60초, 진동 패턴, 점증 간격 — 전부 실측이 아니라 설계 제안이다.
**실기기에서 걸으며 조정해야 한다.** 조정 결과가 나오면 이 문서를 갱신하고
그 근거(무엇을 어떻게 쟀는지)를 함께 적을 것.
