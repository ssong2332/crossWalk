# 오디오 우선순위 정책

사용자 확정: 2026-08-24, **T108 개정 2026-10-12**(아래 §1.1·§2·§4·§6). 구현: `crosswalk_app/lib/services/audio_policy.dart`, `feedback_service.dart`.

## 금지 (다른 모든 규칙보다 우선)
- **P0(안전 경고)를 지연·억제하지 말 것.** 무음 예산·최소 간격은 P0에 적용되지 않는다.
- 낮은 등급을 **큐에 쌓지 말 것.** 늦게 도착한 안내는 정보가 아니라 오정보다. (예외: P1은 대기 슬롯 1칸에서 TTL 3초까지만 기다린다 — §2·§4)
- 이 표에 없는 상황이 나오면 임의 판단하지 말고 표에 행을 추가할지 물을 것.

## 왜 필요한가

시각장애인은 **청각으로 교통 상황을 파악한다.** 앱이 말하는 동안 그 채널이 점유된다.
확장 후보를 모두 더하면 이탈 경고 + 경로 안내 + 신호등 + 물체 경고가 **같은 채널을 두고 경쟁**한다.

정책 도입 전 상태(2026-08-24 실측, `feedback_service.dart`):

| 항목 | 이전 동작 |
|---|---|
| 끊기 규칙 | `_speak()`가 항상 `await _tts.stop()` 먼저 → **나중에 온 말이 무조건 이김** |
| 무음 보장 | 없음 |
| 좌/우 진동 | **완전히 같은 패턴** — 방향 정보가 음성에만 존재 |

마지막 항목이 특히 문제였다. 도로 소음에 음성이 묻히면 **방향 정보가 통째로 사라진다.**

## 2. 끊기 판정표 (재생 중 ↓ / 새 요청 →)

| | P0 | P1 | P2 | P3 |
|---|---|---|---|---|
| **P0 재생 중** | 끊고 교체 | **대기** | 버림 | 버림 |
| **P1 재생 중** | 즉시 끊음 | **대기** (T108; 대체만 끊음 — §6) | 버림 | 버림 |
| **P2 재생 중** | 즉시 끊음 | 즉시 끊음 | 끊고 교체 | 버림 |
| **P3 재생 중** | 즉시 끊음 | 즉시 끊음 | 즉시 끊음 | 끊고 교체 |
| **재생 없음** | 즉시 발화 | 예산 검사 후 발화 (최소 간격이면 **대기**, T108) | 예산 검사 후 발화 | 예산 검사 후 발화 |

"P0 재생 중 + P0 요청"은 §1.1 세부 순위로 정한다.

**대기는 P1만 쓰고, 대기 슬롯은 1개다.** 더 높은 등급만 덮어쓰고, 같은 등급은 먼저 온 것을 지킨다(대체 — §6 Q3 — 일 때만 덮어씀). 슬롯이 차 있으면 새 P1은 버린다(기록 이유 `slot_full`). 단, 넣기 전에 슬롯의 항목이 TTL(§3)을 넘겼으면 먼저 치운다(`say.ttl` 기록) — 만료된 항목이 슬롯을 지키면 안 된다(10/12 기록: P0가 11초 이어지는 동안 만료된 "진입했습니다"가 "건넜습니다"를 버리게 함).
대기 항목은 **재생이 끝나고 최소 간격(1.5초)이 지난 시각**에 꺼낸다(T108 — 전에는 끝나자마자 꺼내서 최소 간격에 다시 버려졌다, 기록 L3367→L3378).

## 4. 무음 보장

| 규칙 | 값 | P0 적용 |
|---|---|---|

P0만 면제하는 이유: 그것만이 "지금 안 들으면 다치는" 정보다.
P0 발화 시간은 예산에 **누적되지 않는다** — 안전 경고가 이후의 안전 경고를 막으면 안 된다.

**20초/60초 한도는 안전 경고(P0)를 빼고 잰다** (T122, 사용자 결정 2026-10-21). P0를 포함한 점유는 기록으로 지켜보고, 실기기에서 사용자 체감(차 소리를 듣기 어려웠는지)으로 판단한다. 근거: `train/audio_occupancy/report_final_set.md` — #130(같은 방향 이탈 묶음)과 문장 단축(T122)을 함께 적용해도 P0 포함 최대 27.3 / 20.9 / 32.5초, P0 제외 최대 13.0초(기록 재계산, 추정).

## 5. 음성을 진동으로 옮기기

음성은 희소 자원이고 진동은 상대적으로 남는다.

| 상황 | 음성 | 진동 |
|---|---|---|
| 첫 이탈 경고 | 발화 | 방향 패턴 |
| **같은 방향 6초 이상 지속** (T120) | **6초마다 1회 재발화** (종전 3초) | 방향 패턴 재발생 (단계별 간격 — 아래 '반복 간격', T132) |
| 반대 방향으로 바뀜 | 즉시 발화 (쿨다운 무시) | 새 방향 패턴 |
| 정상 복귀(front) | 침묵 | 짧은 확인 진동 1회 |
| none / approach | 침묵 | 없음 |

박자로 함께 나간다.

### 진동 패턴

**T136 (사용자 승인, 2026-10-26 실기기)**: 좌우를 **같은 패턴**으로 바꿨다. 방향은 음성으로만 전달하고, 진동은 이탈 정도(아래 반복 간격)를 전한다. 하드웨어 기기로 가면 좌우 모터 2개로 방향을 나눌 계획이다. 서 있는 동안(T133 음성 생략) 방향을 모르는 문제는 걸음을 뗄 때 한 번 말하는 A안(§5.1 T133 표 마지막 줄)으로 메운다. 코드: `VibrationPolicy.directionPattern`.
