## 금지·전제
- 아래 수치 중 '추정'은 실측 아님. 각 행에 확인 방법을 붙였다.

## 4. 말할 것 / 말하지 않을 것 판정표 (초안 — 사용자 확정 전)

| 조건 | 결과 |
|---|---|
| 상태가 위(front/left/right) 또는 hold가 아님 | 검출기 꺼짐 (말 안 함) |
| 검출 물체가 사람 | 말 안 함 |
| 물체가 경로 구역(가운데 1/3) 밖 | 말 안 함 |
| 접지점 거리 > 4m (추정 기준) | 말 안 함 |
| 경로 구역 + ≤ 4m + 점수 ≥ 기준, **연속 2회 미만** | 기다림 |
| 위 조건 연속 2회 이상, 이번 횡단에서 처음 | 진동(새 패턴) 즉시 + "앞에 장애물" |
| 같은 물체(상자 겹침)로 이미 알림 | 말 안 함 (진동만 3초 간격, 추정) |
| P0 이탈 경고 재생 중 | 진동만 즉시, 음성은 끊지 않음, TTL 1초 넘으면 버림 (등급 위치는 **사용자 결정** — 아래 문제 1) |
| "차도입니다"(P0-1) 재생 중 | 진동만 |
| 거리 ≤ 1m인데 처음 검출 | 말 안 함? 진동만? → **사용자 결정** (늦은 안내 = 오정보 원칙, `AudioPolicy.md` 금지 2번째 줄) |
| 접근(움직이는) 오토바이·자전거 | 이번 범위 밖 — 말 안 함 |

## 5. 추천안과 첫 실험

추천: **A를 유지한 채 PC 0~1단계 실험을 먼저**, 통과하면 **D안**으로 앱 설계.
이유: (1) 사용자 전제의 직접 근거가 없고 빈도를 모름, (2) 오경보 피해가 '차도 한가운데 멈춤'이라 횡단 중이 오히려 가장 비싼 구간, (3) 방향을 주는 C안은 이탈 안내와 충돌.

| 단계 | 내용 | 실행 | 합격 기준 (제안값 — 사용자 확정 필요) |
|---|---|---|---|
| 0 | 보유 영상 34개에서 건너기마다 "경로 구역 4m 안에 사람 아닌 물체가 있었나" 사람이 표시, 종류·위치 기록 | 추론 없음, 눈 검토 | 그런 건너기가 **10건 중 1건 이상**이면 1단계로. 미만이면 A 유지하고 끝 |
| 1 | 같은 프레임에 COCO 사전학습 SSDLite(차·오토바이·버스·트럭·자전거 그대로 있음) + T107 모델(볼라드) 오프라인 실행 | PC 추론 — **승인 필요** | 2m 지점 도달 전 검출 재현 ≥ 80% / 오경보 ≤ 건너기 20회당 1회 / PC ≤ 50ms |
| 2 | 1단계 실패가 시점 차이 때문이면: AI Hub 합친 클래스(볼라드+차량+오토바이+자전거, 사람 제외)로 재학습, 앱 시점 프레임으로만 시험 | 학습 — 승인 필요 | 1단계 기준 동일 |
| 3 | 폰 실측 (T117 빌드 위) | 실기기 | 폰 추론 ≤ 150ms, 횡단 중 분류기 주기 저하 ≤ 20% |

## 문제/다음 단계
1. 물체 안내 오디오 등급이 AudioPolicy 표에 없음 → 사용자에게 행 추가 결정 요청(P0 세부 순위 안에 넣을지, 진동 전용으로 할지).
2. 피하는 동안의 이탈 경고: 정차 차량을 돌아가면 이탈 경고가 정상 동작으로 울림 — 검출 중 이탈 경고를 줄일지(위험)는 별도 결정.
3. 차가 줄무늬를 가리면 분류기·각도 모델이 흔들릴 수 있음(추정) — 0단계 영상 검토 때 같이 표시 권장.
4. 0단계 합격선 "10건 중 1건"은 근거 없는 제안값.
