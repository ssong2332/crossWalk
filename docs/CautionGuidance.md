# 주의 구역 안내 판정표 (C: 맨홀·그레이팅 / 가로수 구역)

**상태: 사용자 확정 (2026-10-01, Q1~Q5 제안안 채택), 앱 미구현.** Q5에 따라 B 실기기 결과를 받은 뒤 T105 모델로 바꾸면서 구현한다. 태스크: `docs/Tasks.md` T105.
입력 모델: `model/crosswalk_surface_t105.onnx` (LR-ASPP MobileNetV3-Small, 224, 클래스 9 — 앱 미반영).
B(점자블록·차도) 판정표 `docs/SurfaceGuidance.md`와 같은 분할 결과·같은 영역을 쓴다.

## 금지 (다른 모든 규칙보다 우선)
- 이 표에 없는 상황에서 말하지 않는다. 표에 없는 상황이 나오면 행을 추가할지 사용자에게 묻는다.
- `docs/SurfaceGuidance.md`의 금지 규칙을 그대로 따른다: 횡단보도 안내 중(분류기 위·hold) 침묵, 이탈 경고(P0)를 끊거나 늦추지 않음, 연속 확인 전에는 말하지 않음.
- **계단은 이 표로 안내하지 않는다.** T105 모델의 계단 IoU 0.168, 발 앞 재현 33.3%(n=9) — 계단 보강 재학습 후 다시 정한다(T105 NOT DONE).
- **주의 구역 안내가 B 안내를 밀어내지 않는다.** 같은 판정에서 B 이벤트(차도·멈춤 블록·선형 방향)와 겹치면 B만 말한다.

## 1. 입력 — 분할 결과에서 무엇을 읽는가

앞(F) 영역만 쓴다: 가운데 1/3 × 아래 1/2 (`docs/SurfaceGuidance.md` §1과 같음).

| 값 | 정의 (Q3 확정) | 근거 (test 4,718장, `train/caution_front_t105.log`) |
|---|---|---|
| 앞 맨홀·그레이팅 있음 | F의 맨홀·그레이팅 ≥ **10%** | 정답 5% 이상 대비 재현 84.1% · 정밀도 83.6% · 경보율 3.5% |
| 앞 가로수 구역 있음 | F의 가로수 구역 ≥ **10%** | 정답 5% 이상 대비 재현 88.0% · 정밀도 75.9% · 경보율 1.2% |

면적 기준별 비교 (정답은 F의 5% 이상, 경보율 = 예측이 기준 이상인 사진 비율):

| 기준 | 맨홀·그레이팅 재현 / 정밀도 / 경보율 | 가로수 구역 재현 / 정밀도 / 경보율 |
|---|---|---|
| 5% | 92.1% / 72.2% / 4.4% | 92.0% / 61.3% / 1.6% |
| **10% (제안)** | **84.1% / 83.6% / 3.5%** | **88.0% / 75.9% / 1.2%** |
| 15% | 77.4% / 85.8% / 3.1% | 78.0% / 81.2% / 1.0% |
| 25% | 56.7% / 85.3% / 2.3% | 58.0% / 90.6% / 0.7% |

10%를 고른 이유: 5%→10%에서 정밀도가 크게 오르고(맨홀 +11.4, 가로수 +14.6) 재현은 덜 떨어진다(−8.0, −4.0). 15% 이상은 재현 손실이 정밀도 이득보다 크다.

## 2. 언제 판정하는가

B와 같다: 같은 분할 결과(처리 프레임 10개 중 1번), **연속 2회 확인**, 분류기 상태 **none / crossed**에서만.

## 3. 판정표

| # | 분류기 상태 | 조건 (연속 확인 후) | 안내 | 등급 | 반복 |
|---|---|---|---|---|---|
| C1 | none / crossed | 앞 맨홀·그레이팅 없음 → **있음** | "발밑 주의" (Q1 확정) | P2 | 1회. 3초 이상 없었다가 다시 나타나야 다시 말함 (B 3번 멈춤 블록과 같은 방식) |
| C2 | none / crossed | 앞 가로수 구역 없음 → **있음** | "가로수" (Q2 확정) | P2 | C1과 같음 |
| C3 | none / crossed | C1·C2가 B 이벤트(B 1~3·6~8번)와 같은 판정에서 남 | B만 말함, C는 버림 (그 등장에 대해 다시 말하지 않음) | — | — |
| C4 | none / crossed | 계단 | 침묵 (금지 3번) | — | — |
| C5 | approach | 무엇이든 | 침묵 — "앞에 횡단보도가 있습니다"(기존)와 겹침 | — | — |
| C6 | 위(front/left/right) / hold | 무엇이든 | 침묵 (횡단보도 안내 우선) | — | — |
| C7 | 무판정·오류 | 무엇이든 | 침묵 | — | — |

**우선순위**: C1·C2는 P2 — 무음 예산(1.5초 간격, 60초에 20초)을 따르고, 예산에 걸리면 버린다(큐에 쌓지 않음). 맨홀·그레이팅이 많은 길에서도 예산이 소리 점유를 막는다(PRD C행 "빈도 높은 경고가 오디오 채널을 점유" 대응).

## 4. 진동

C1·C2 모두 **진동 없음** (초안 제안 그대로 확정). 이유: B §4와 같음 — 기존 좌/우 패턴은 "이탈 방향"을 뜻하고, 차도 ‧‧‧는 P0 전용이라 새 패턴을 늘리면 구분이 어려워진다.

## 6. 이 문서의 값은 추정이다

10% 기준, 연속 2회, 3초 재무장은 설계 제안이다. 근거 수치는 **사진 단위** test 평가이고, 걸으면서 몇 번 울리는지(이벤트 단위)는 연속 영상이 없어 재지 못했다(T104 (12)와 같은 한계). 경보율 3.5%는 "프레임마다 울릴 비율의 상한"일 뿐, 실제 발화 횟수는 1회 규칙·재무장·무음 예산으로 더 적다(추정). 실기기 보행으로 조정한다.
